# My Jetpack Compose Journey 🚀

Welcome to my personal learning repository! This project is not a single production app, but rather a comprehensive collection of my practice codes, experiments, and references while learning **Android Development** and **Jetpack Compose**. 

I use this repository as my personal code dictionary. Whenever I need to implement a specific feature in a real project, I refer back to the implementations here.

## 📚 Topics Covered

Based on the package structure, this repository includes hands-on practice for:

* **`animation_learn`**: Custom animations and transitions in Jetpack Compose.
* **`data_store`**: Managing user preferences securely using Jetpack DataStore.
* **`navigation` & `navigationpractice`**: Screen routing and passing arguments using Navigation Compose.
* **`todoapp`**: A complete mini-project implementing Room Database, DAO, Repository pattern, and MVVM architecture.
* **`notification_learning`**: Creating, managing, and handling custom Android notifications.
* **`screen_overlay_learning`**: Implementing floating windows (System Alert Window) drawing over other apps.
* **`UsageAccess`**: Working with Usage Stats API, foreground app detection, and background services.
* **`jetpackcompose`**: Basic to advanced UI components, layouts, and Material 3 design implementations.

## 🛠 Tech Stack

* **Language**: Kotlin
* **UI Toolkit**: Jetpack Compose, Material 3
* **Architecture**: MVVM (Model-View-ViewModel)
* **Local Storage**: Room Database, DataStore Preferences
* **Concurrency**: Kotlin Coroutines & Flow

## 🚀 How to Use

Since this is a reference project, you can explore the individual packages inside `app/src/main/java/agecalabir/android/myjetpackcompose/` to find specific feature implementations. Each package is somewhat independent and focuses on a single Android concept.
